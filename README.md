# bcroutetosuccess.com

The website for **Route to Success**, a student club at BASIS Chandler that runs a yearly Math Competition and takes part in school Events.

Built with [Astro](https://docs.astro.build), using React for interactive components, and hosted on Cloudflare Pages.

## Getting started

Requires Node.js 22.12 or newer.

```sh
npm install
npm run dev
```

Then open http://localhost:4321.

| Command           | What it does                                  |
| :---------------- | :-------------------------------------------- |
| `npm run dev`     | Start the local dev server                    |
| `npm run build`   | Build the site into `./dist/`                 |
| `npm run preview` | Preview the built site before deploying       |

## Where things live

- `src/pages/`: one file per page on the site
- `public/`: images and files served as they are, such as the logo and the Sponsorship Prospectus
- `CONTEXT.md`: what words like Division, Stage and Entry Fee mean on this site
- `docs/adr/`: why big decisions were made

## Before you commit

This repo is public. Never commit registration data, form responses, photos without a Photo Release, or anything with a child's name.
